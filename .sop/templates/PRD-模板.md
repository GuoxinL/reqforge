- **非目标(Non-goals)**:明确不做、不修改什么

## 视觉规格引用规范(涉及页面设计时)

> 凡功能涉及**页面布局、颜色、样式、交互状态**时,MD 只描述功能行为,**不展开视觉细节**;视觉细节写入独立的 HTML 视觉规格文件。

1. 视觉规格文件:需求目录内 `视觉规格-<模块>.html`(模板:`templates/视觉规格-模板.html`),按需生成;一个模块对应一个 `<section id="module-xxx">`;
2. MD 中对应 FR 下引用,格式:
   `- 视觉规格:[PRD-xxx-视觉规格.html#module-xxx](PRD-xxx-视觉规格.html#module-xxx)`(锚点与 section id 必须一致);
3. 不涉及视觉的功能无需生成视觉规格文件,不要留空引用。

## 编写规范提醒(给 AI 的执行约束)

1. **禁止模糊词**:快速 / 友好 / 流畅 / 大概 / 可能 / 等等 → 全部换成可测量表述。
2. **先问题后方案**:1 背景先写问题与用户价值,不先写"我们要做个 XX 页面"。
3. **异常流程必写**:只写正常流程 = 未完成。
4. **验收标准必须可测试**:不能测的验收标准等于没写。
5. **指标必须有基线值 + 目标值 + 时间窗**,且系统可采集。
6. 正文只表达"做什么",补充信息放参考资料。
